# WMS А2 — Товары на складе

Тестовое задание на позицию Junior Web-разработчик: интерфейс экрана «Товары на складе» складской системы WMS А2.

## Функциональность
- Поиск по товару и SKU
- Фильтр по статусу
- Таблица товаров с цветовым кодированием статусов (адаптивная — карточки на мобильных, таблица на широких экранах)
- Карточка товара по клику на строку / кнопку «Открыть»

## Стек
React + Tailwind CSS, данные хранятся в статическом массиве (без backend и БД).
