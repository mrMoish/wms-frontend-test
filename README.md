# WMS А2 — Товары на складе

Интерактивный экран складской системы управления (WMS) для просмотра, поиска и фильтрации товаров.

## Обзор

Одностраничное приложение, реализующее экран «Товары на складе». Включает таблицу с визуально различимыми статусами, живой поиск по названию и SKU, фильтрацию и модальные карточки с детальной информацией.

**Функционал:**

- Живой поиск по названию товара и артикулу (SKU)
- Фильтрация по статусу: «Готов к отгрузке», «На хранении», «На сборке», «Списан»
- Цветовая индикация статусов (включая пульсацию для товаров «На сборке»)
- Модальная карточка товара с полной информацией (категория, вес, дата, описание)
- Адаптивная вёрстка (десктоп, планшет, мобильные устройства)
- Управление с клавиатуры (закрытие модалки по `Escape`, фокусировка)

## Технологии

Проект написан на чистых веб-стандартах без использования фреймворков и сборщиков.

| Слой        | Технология                                                        |
|-------------|-------------------------------------------------------------------|
| Разметка    | Чистый HTML5                                                      |
| Стили       | Чистый CSS3 (переменные, Grid, Flexbox, анимации, медиа-запросы) |
| Логика      | Чистый JavaScript (ES5, без зависимостей)                         |
| Шрифт       | Google Fonts — DM Sans                                            |
| Иконки      | Font Awesome 6 (CDN)                                              |
| Данные      | JavaScript-массив (имитация базы данных, бэкенд не требуется)     |

## Запуск локально

1. Клонировать репозиторий:
   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd wms-a2
   ```

2. Для корректной работы достаточно открыть `index.html` через любой локальный сервер (чтобы без проблем загрузились шрифты и иконки):
   ```bash
   # Вариант 1: npx
   npx serve .

   # Вариант 2: Python
   python3 -m http.server 8000
   ```

*Также можно просто открыть `index.html` двойным кликом в браузере.*

## Статусы товаров

| Статус              | Цвет    | Визуальное поведение               |
|---------------------|---------|------------------------------------|
| Готов к отгрузке    | Зелёный | Статичный бейдж со светящейся точкой |
| На хранении         | Голубой | Статичный бейдж со светящейся точкой |
| На сборке           | Жёлтый  | Бейдж с пульсирующей точкой        |
| Списан              | Красный | Статичный бейдж со светящейся точкой |

При наведении на строку таблицы слева появляется цветная полоса, соответствующая статусу товара.
