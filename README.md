# WMS А2 — Товары на складе

Интерактивный экран складской системы управления (WMS) для просмотра товаров, фильтрации по статусу и поиска по SKU или названию.

## Обзор

Одностраничное приложение, реализующее экран «Товары на складе». Включает таблицу товаров с визуально различимыми статусами, живой поиск, фильтрацию и модальные карточки с детальной информацией о каждой позиции.

**Основной функционал:**

- Живой поиск по названию товара и SKU
- Фильтрация по статусу: «Готов к отгрузке», «На хранении», «На сборке», «Списан»
- Цветовая индикация статусов с анимированными бейджами
- Модальная карточка товара с полной информацией
- Адаптивная вёрстка для десктопа, планшета и мобильных устройств
- Навигация по клавиатуре (Escape для закрытия модалки, фокус на элементах)

## Технологии

| Слой        | Технология                                           |
|-------------|------------------------------------------------------|
| Разметка    | Чистый HTML5                                         |
| Стили       | Чистый CSS3 (переменные, Grid, Flexbox, анимации)    |
| Логика      | Чистый JavaScript (без фреймворков и сборщиков)      |
| Шрифт       | Google Fonts — DM Sans                               |

Никаких зависимостей и пакетных менеджеров — один HTML-файл, который открывается напрямую в браузере.

## Как запустить локально

1. Клонировать репозиторий:
   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd wms-a2
   ```

2. Открыть `index.html` в браузере двойным кликом или через терминал:
   ```bash
   # macOS
   open index.html
   
   # Linux
   xdg-open index.html
   
   # Windows
   start index.html
   ```

Либо использовать любой локальный сервер (например, `npx serve .` или `python3 -m http.server`).

## Статусы товаров

| Статус              | Цвет    | Поведение                       |
|---------------------|---------|---------------------------------|
| Готов к отгрузке    | Зелёный | Статический бейдж              |
| На хранении         | Голубой | Статический бейдж              |
| На сборке           | Жёлтый  | Пульсирующая точка (анимация)  |
| Списан              | Красный | Статический бейдж              |
